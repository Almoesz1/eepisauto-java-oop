Software Engineering

⚙️ 3. CONTROLLER (Orkestrator Event)
`PrimaryController.java` menangani event navigasi, manipulasi koleksi showroom/garasi, validasi transaksi, dan komunikasi dua arah dengan View.

⬇ Eksekusi Aturan Bisnis
Model Mutation: `currentUser.buyVehicle(car)` memotong saldo, mengurangi stok, menambah ke garasi, memicu bonus tier.
⬇ Update Tampilan
View Refresh: Saldo sidebar terupdate, bar chart tergambar ulang, modal faktur dibuka.
OOP Deep Dive

1. Abstraction & Inheritance

Prinsip Pemrograman Objek
🔒 Mengapa Abstract Class?
Kelas User, Customer, dan Vehicle dideklarasikan sebagai abstract untuk mencegah instansiasi objek yang belum spesifik secara bisnis.
🌲 Hierarki Inheritance 1: Pengguna
User (Abstract)
 ↳ Customer (Abstract)
    ↳ GoldCustomer (Tier VVIP)
    ↳ SilverCustomer (Tier VIP)
    ↳ RegularCustomer (Standar)
🏎️ Hierarki Inheritance 2: Kendaraan
Vehicle (Abstract, implements ITaxable)
 ↳ ElectricCar (EV: baterai kWh & jarak)
 ↳ GasCar (Bensin: kapasitas cc & transmisi)
☕ Vehicle.java & ElectricCar.java
// 1. Base Abstract Class dengan kontrak baku public abstract class Vehicle implements ITaxable { protected String brand, model, color; protected double price; protected int stock; public Vehicle(String brand, String model, double price, int stock, String color) { this.brand = brand; this.model = model; this.price = price; this.stock = stock; this.color = color; } // Kontrak Abstrak: Wajib dioverride oleh seluruh subclass public abstract String testDrive(); public abstract String getSpecs(); } // 2. Subclass Konkret yang mewarisi sifat induk public class ElectricCar extends Vehicle { private int batteryCapacity, range; public ElectricCar(String brand, String model, double price, int stock, String color, int battery, int range) { super(brand, model, price, stock, color); this.batteryCapacity = battery; this.range = range; } @Override public String testDrive() { return "Zzzzz... Melaju instan nan senyap bertenaga EV."; } }
OOP Deep Dive

2. Polymorphism (Dynamic Method Dispatch)

Prinsip Pemrograman Objek
🎭 Definisi & Manfaat
Polimorfisme memungkinkan pemanggilan method yang seragam pada objek bertipe induk, namun eksekusi perilakunya ditentukan secara dinamis oleh subclass saat runtime.
1. Overriding `testDrive()`
• ElectricCar: "Zzzzz... Senyap bertenaga EV."
• GasCar: "VROOOM! Suara mesin menderu!"
2. Overriding `calculateDiscount()`
• Gold: Diskon 8%  ·  Silver: 3%  ·  Regular: 0%
3. Overriding `applyBonus()`
• Gold: Cashback Saldo 2% + Asuransi 3 Tahun.
• Silver: Gratis servis 1 tahun & merchandise.
☕ PrimaryController.java & GoldCustomer.java
// 1. Pemanggilan Polimorfis Seragam di Controller (Runtime Dispatch) double discount = currentUser.calculateDiscount(vehicle.getPrice()); double finalPrice = (vehicle.getPrice() - discount) + tax; // Memicu perilaku bonus spesifik tier tanpa perlu 'if-else' bertumpuk String bonusBrought = currentUser.applyBonus(finalPrice); String soundEffect = vehicle.testDrive(); // 2. Implementasi Konkret pada Subclass: GoldCustomer public class GoldCustomer extends Customer { @Override public String getTierName() { return "Gold VVIP"; } @Override public double calculateDiscount(double price) { return price * 0.08; // Potongan 8% khusus Gold } @Override public String applyBonus(double finalPrice) { double cashback = finalPrice * 0.02; this.bankBalance += cashback; // Refund saldo instan! return "Cashback Saldo Rp " + String.format("%,.0f", cashback) + " & Asuransi All-Risk 3 Thn"; } }
OOP Deep Dive

3. Encapsulation & Data Integrity

Prinsip Pemrograman Objek
🛡️ Proteksi Atribut Kritis
Menjaga integritas data finansial agar saldo pengguna tidak dapat dimanipulasi sembarangan dari luar kelas tanpa melewati logika validasi bisnis.
1. Atribut Terproteksi
• protected double bankBalance; di kelas `Customer`.
• protected int stock; di kelas `Vehicle`.
Akses baca hanya melalui getter resmi getBankBalance().
2. Alur Transaksi Terenkapsulasi
1. Validasi stok unit kendaraan.
2. Kalkulasi diskon tier dan pajak PPN 11%.
3. Verifikasi kecukupan saldo (Lempar exception jika kurang).
4. Mutasi saldo, penurunan stok, dan penambahan garasi.
☕ Customer.java — Enkapsulasi Transaksi Aman
// Mutasi saldo hanya diizinkan melalui method berintegritas tinggi public String buyVehicle(Vehicle vehicle) throws DealershipException { // 1. Validasi ketersediaan stok fisik if (vehicle.getStock() <= 0) { throw new DealershipException("Stok " + vehicle.getModel() + " kosong!"); } double discount = calculateDiscount(vehicle.getPrice()); double discountedPrice = vehicle.getPrice() - discount; double tax = vehicle.calculateTax(discountedPrice); double finalPrice = discountedPrice + tax; // 2. Validasi saldo akun terenkapsulasi if (this.bankBalance < finalPrice) { throw new DealershipException("Saldo tidak mencukupi! Kurang: Rp " + String.format("%,.0f", (finalPrice - this.bankBalance))); } // 3. State data hanya dimutasi jika seluruh validasi lolos this.bankBalance -= finalPrice; vehicle.decreaseStock(); this.garage.add(vehicle); String bonus = applyBonus(finalPrice); return TransactionReceipt.generateReceipt(this, vehicle, finalPrice, discount, tax, bonus); }
